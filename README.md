# 🛒 Lista de Compras

Um aplicativo mobile simples e direto para organizar e gerenciar sua lista de compras no dia a dia.

## 🚀 Tecnologias

- **React Native**
- **Expo**
- **TypeScript**

## 💻 Como executar

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Inicie o projeto:**
   ```bash
   npx expo start
   ```

3. **Abra o aplicativo:**
   - Escaneie o código QR no terminal usando o aplicativo **Expo Go** no celular.
